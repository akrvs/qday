# CryptoMap

Continuous cryptographic inventory (CBOM) and post-quantum migration tracker.

Discovers quantum-vulnerable cryptography (RSA, ECC, ECDSA, DH) across code,
certificates, and TLS endpoints; produces a CycloneDX Cryptographic Bill of
Materials; risk-ranks assets; and tracks migration progress against CNSA 2.0
and NIST deadlines.

**Status:** architecture design phase — no code yet.
